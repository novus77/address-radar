# Address-only migration resource boundary checkpoint

## Approved scope

Correct the reviewed output-path, memory, original-deadline and cohort SQL accounting gaps. Preserve business rules, existing SQLite data and backups, FOMO browser/login processes, and disabled gateway delivery. This checkpoint does not authorize fabricated fence evidence or substitute tests for production cutover receipts.

## Changes

- The final snapshot exporter validates every output ancestor and retains a directory descriptor for exclusive file creation. Ancestor identities are checked before publication and after fsync.
- SQLite enforces a conservative per-record length limit before Python conversion. Encoded row bytes are charged cumulatively while rows are read. The previous connection limit is restored on success or refusal.
- One monotonic operation clock covers pinned configuration/module reads, native collection, SQLite reads, validation and publication. A shorter kernel job budget is clipped relative to the original start, not loading completion. Native CLI execution also uses SIGALRM.
- Final plan preparation consumes an explicitly pinned final capture and receipt instead of the October 7 rehearsal seed. Output uses a retained directory descriptor through Linux procfs. The CLI supervisor enforces a 30-second hard child lifetime, 128 MiB V8 heap limit and 64 KiB combined output limit.
- The address-only first-write adapter reserves both generation SQL statements, charges their elapsed time against the importer budget, and checks expiry before and after those queries. Accounting remains inside the receipt digest; the coordinator's exact four-field receipt contract is unchanged.

## Verification and interpretation

Targeted checks cover oversized SQLite values, ancestor symlinks/ownership, original and shorter deadlines, a synchronously blocked worker, excessive child output, and exact callback receipt shape. The exporter composition test uses an in-memory registry and a clearly mocked kernel; it is not a native source fence proof.

The production host runs Python 3.12.3, which supports SQLite connection length limits. Older local Python versions lacking this API fail closed; local Python tests use the bundled runtime. The migration role currently has generation table SELECT/INSERT permission. No permission change was necessary.

Before this checkpoint, six business services were active with zero restarts, disk free space was approximately 23 GiB, and production generation/cohort/first-write tables were empty. SQL admission control was not installed. Installing reviewed maintenance code alone must not be described as a production release switch or a completed data migration.
